JobFlow · Design System

Styleguide

Ein editoriales Dossier-System: flache Flächen, Haarlinien, strenges Raster. Jede Farbe leitet sich aus wenigen Quellen ab — eine Markenfarbe, drei Neutral-Achsen, fünf Statustöne.

Typo — Newsreader · Hanken Grotesk · Space Mono Akzent — Editorial Green Tokens — variables.css
01

Zwei Ebenen

Die Tokens sind in zwei Schichten aufgebaut. Ebene 1 hält die wenigen Grundwerte, aus denen alles abgeleitet wird — hier wird angepasst. Ebene 2 benennt jeden Token nach seinem Einsatzort und referenziert nur Ebene 1.

Ebene 1

Grundwerte

Die Quellen. Eine Handvoll Werte, aus denen sich der gesamte Rest mischt.

  • --brand — das eine Grün
  • --hue-surface / line / ink
  • --status-ink-l / soft-l
  • --family-serif / sans / mono
Ebene 2

Semantik

Benannt nach Einsatzort. Referenziert ausschließlich Ebene 1 — nie ein roher Wert.

  • --bg-page · --surface · --border
  • --text · --text-muted · --text-faint
  • --accent · --accent-soft · --accent-deep
  • --status-angebot · --status-absage …
Ein Wert genügt:  --brand ändern → der gesamte Akzent-Fächer zieht nach. Eine Hue-Achse drehen → alle Neutraltöne kippen mit.

03

Akzent

Eine einzige Markenfarbe — ein tiefes redaktionelles Grün. Jeder weitere Akzentton entsteht per color-mix aus genau dieser Quelle. Wird sie getauscht, bewegt sich der ganze Fächer mit.

06

Fünf Stationen der Pipeline, jede mit einem eigenen Farbton. Jeder Status ist ein Paar: ein kräftiger, lesbarer Vordergrund (·ink) und eine fast weiße Fläche (·soft). Die Helligkeit ist je Rolle konstant — nur Farbton und Sättigung wechseln.

08

Notiz zur Benennung

Beim Übertrag aus dem Prototyp (styles.css) in die Token-Datei sind ein paar Namen vereinheitlicht worden. Werte sind identisch — nur die Bezeichnung folgt jetzt dem Einsatzort.

--line  →  --border
Haarlinie, gleicher Wert
--line-2  →  --border-strong
kräftige Linie, gleicher Wert
--ink / --text  →  --text
zusammengeführt — aktiver Chip nutzt diesen Ton als Fläche
--surface-2 / -3  →  --surface-muted / -sunken
nach Tiefe benannt statt nummeriert
